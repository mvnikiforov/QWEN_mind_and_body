# Proposal

## Why

Строка «ТЕЛО • ЧУВСТВА • РАЗУМ • ДУХ» в hero выровнена по левому краю колонки, тогда как остальной текст первого экрана на мобильных выровнен по левому краю, но сама строка — короткая центральная композиционная метка, обрамлённая линейками `border-y` во всю ширину блока. Из-за этого между левым краем линейки и первым словом образуется заметный пустой отступ (около 21px при ширине 390px), а сама строка смещена влево от визуального центра экрана — при том что блок симметричен относительно экрана. На мобильных это выглядит как случайное смещение, а не как замысел.

## What Changes

- На ширинах меньше `lg` строка ключевых слов центрируется по горизонтали внутри своего блока: текст «ТЕЛО • ЧУВСТВА • РАЗУМ • ДУХ» располагается симметрично относительно контентной области.
- Горизонтальные линейки блока (`border-y`) остаются на всю ширину колонки — центрируется только текст, обрамление не меняется.
- Выравнивание по центру не меняет ни кегль, ни трекинг, ни отступы разделителей: строка по-прежнему занимает одну строку на 390px и не выходит за границы экрана.
- На ширинах `lg` и больше выравнивание остаётся по левому краю, как сейчас; десктопная композиция не затрагивается.

## Capabilities

### New Capabilities

_(нет)_

### Modified Capabilities

- `hero-keywords`: требование «Desktop appearance unchanged» дополняется явным правилом выравнивания — по центру на мобильных, по левому краю на десктопе; линейки обрамления при этом остаются во всю ширину.

## Impact

- `src/components/Hero.tsx:265`: класс абзаца со словами — добавляется мобильное центрирование по горизонтали (`max-lg:justify-center`, то есть только на ширинах меньше `lg`; на десктопе не добавляется ни одного правила и выравнивание остаётся по левому краю); уточняется комментарий над блоком (`:253-263`).
- Публичный API, зависимости, сборка и остальные секции сайта не меняются. Затрагивается только горизонтальное выравнивание одной строки в первом экране на ширинах < 1024px.
