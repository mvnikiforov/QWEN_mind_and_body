# Spec Delta

## Purpose

Определяет вертикальный ритм секции hero: расстояние от фиксированной шапки до первого видимого контента (строки «Онлайн и очно») на разных ширинах экрана. Существует, чтобы первый экран на мобильных не содержал пустой полосы и чтобы зазор оставался корректным при любом состоянии safe-area.

## ADDED Requirements

### Requirement: Compact top gap on mobile and tablet
На ширинах экрана меньше breakpoint `lg` секция hero ДОЛЖНА располагать первый контент (строку «Онлайн и очно») на расстоянии не более 16px от нижнего края фиксированной шапки в её непроскролленном состоянии.

#### Scenario: Mobile viewport shows no empty band below header
- **WHEN** страница открыта на экране шириной менее `lg` и шапка ещё не упёрлась в состояние `scrolled`
- **THEN** расстояние между нижним краем шапки и верхним краем строки «Онлайн и очно» составляет около 8px и не превышает 16px
- **AND** пустая полоса между шапкой и контентом не видна

#### Scenario: Tablet viewport uses the same compact gap
- **WHEN** страница открыта на экране шириной от `sm` (640px) до `lg` (1024px)
- **THEN** применяется тот же компактный верхний отступ, что и на телефонах
- **AND** первая строка hero располагается не более чем в 16px под шапкой

#### Scenario: Content never hides behind the fixed header
- **WHEN** страница открыта на экране шириной менее `lg`
- **THEN** первая строка hero не перекрывается фиксированной шапкой ни при одном значении `env(safe-area-inset-top)`

### Requirement: Desktop spacing unchanged
На ширинах `lg` и больше верхний отступ секции hero ДОЛЖЕН оставаться равен текущему значению (144px отступ секции + 40px внутренний отпуск), чтобы десктопная композиция hero не изменилась.

#### Scenario: Desktop viewport keeps current top spacing
- **WHEN** страница открыта на экране шириной `lg` или больше
- **THEN** секция hero применяет верхний отступ 144px и внутренний отступ 40px
- **AND** визуальная композиция hero совпадает с текущей

### Requirement: Gap derives from header height
Значение верхнего отступа hero на мобильных ДОЛЖНО вычисляться из фактической высоты фиксированной шапки (с учётом `env(safe-area-inset-top)`), а не быть независимой константой, чтобы изменение шапки не оставляло пустой зазор или наложение.

#### Scenario: Header height change keeps the gap constant
- **WHEN** высота мобильной шапки изменяется (например, при изменении её вертикальных отступов или safe-area)
- **THEN** верхний отступ hero пересчитывается так, чтобы зазор до первой строки оставался равен целевому значению из требования «Compact top gap on mobile and tablet»

#### Scenario: Shared constant with scroll offset
- **WHEN** страница использует якорную навигацию по секциям
- **THEN** значение отступа прокрутки (`scroll-padding-top`) остаётся не меньше высоты шапки, чтобы заголовок целевой секции не скрывался под шапкой

### Requirement: No change to hero visual geometry
Сокращение отступа ДОЛЖНО затрагивать только расстояние до первого контента и не менять геометрию кругового визуала: масштаб 0.9, сдвиги фраз 23px, вертикальные резервы `pt-[28%]`/`pb-[20%]` остаются как есть.

#### Scenario: Hero visual unchanged on mobile
- **WHEN** страница открыта на экране шириной менее `lg`
- **THEN** круговый визуал отображается с масштабом 0.9 и сдвигами фраз 23px согласно capability `hero-visual`
- **AND** положение визуала относительно заголовка hero не изменено
