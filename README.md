# Валерия · ПРО|БАЛАНС — сайт-витрина психолога

Одностраничный сайт-магазин услуг: терапевтические сессии, практики ПРО|БАЛАНС,
пакет «Баланс», афиша мероприятий, форма записи с мини-анкетой, админ-панель.

**Стек:** React + Vite + Tailwind CSS v4. «База данных» — localStorage браузера
(таблицы users / services / orders / events / posts / content, версия схемы 4).

## Локальная разработка

```
npm install
npm run dev     # http://localhost:3000
npm run build   # production-сборка в папку dist
```

## Админ-панель

Адрес: `/#/admin` (ссылка «Для администратора» в подвале). Первый вход: **admin / valeria** — сразу смените пароль во вкладке «Настройки».

| Вкладка | Возможности |
|---|---|
| Заказы | статусы Новый → Оплачен → Проведена встреча → Закрыт, анкета клиента, удаление |
| Витрина | карточки и оба формата каждой (цена, фото, описание, пакет, бейджи) |
| Афиша | мероприятия, формат, цены, описания |
| Контент | фото «Обо мне», тексты, баннер «Мультикультурный подход», контакты, URL автоподгрузки МАХ |
| Канал | публикации для блока «Актуальное из канала» |
| Настройки | пароль, экспорт/импорт базы, сброс, документация |

**Резервное копирование:** «Настройки» → Экспорт базы → сохранить JSON. Восстановление — Импорт базы.

## Деплой

### Статический хостинг (Netlify / Vercel / GitHub Pages)
`npm run build` → загрузить содержимое `dist/` (Netlify Drop: просто перетащить папку).

### Деплой на reg.ru (shared-хостинг)
1. Локально: `npm run build` → появится папка `dist/`.
2. В файловом менеджере откройте корень сайта — `public_html/` (или `www/<домен>/`).
3. **Удалите всё** (включая ошибочно загруженные `src/`, `node_modules/`).
4. Загрузите **содержимое** `dist/` (`index.html` и папку `assets/`) — не саму папку `dist`!
5. Загрузите `deploy/htaccess` в `public_html/` и переименуйте в `.htaccess`.
   Он задаёт MIME-типы (чинит ошибку «Failed to load module script»), сжатие, кэш и SPA-перезапись.
6. Сайт размещается в корне домена; в подкаталоге работать не будет.

### VDS + nginx
```
sudo cp deploy/nginx.conf /etc/nginx/sites-available/probalance
sudo ln -s /etc/nginx/sites-available/probalance /etc/nginx/sites-enabled/
sudo nginx -t && sudo systemctl reload nginx
sudo certbot --nginx -d vash-domen.ru
```
Быстрая загрузка файлов: `bash deploy/deploy.sh user@ip-сервера`.

### Docker
```
docker compose -f deploy/docker-compose.yml up -d --build
```

### Перенос данных между устройствами
Админка → «Настройки» → «Экспорт базы» → на новом устройстве «Импорт базы».

## Интеграция с каналом МАХ
Блок «Актуальное из канала» пробует автоподгрузку по URL из «Контент → URL автоподгрузки»
(RSS/JSON, формат `[{"date","title","text","image"}]`). Пока API нет — публикации
обновляются вручную во вкладке «Канал».

## Развитие
Для production-роста: серверная БД (PostgreSQL/Supabase) вместо localStorage,
почтовые уведомления о заявках, bcrypt-хэширование паролей.
