# Валерия · ПРО|БАЛАНС — сайт-витрина услуг психолога

Одностраничный сайт в восточной минималистичной эстетике (инь-ян, круг целостности):
витрина услуг, афиша с записью, форма с мини-анкетой, FAQ, «живой поток» канала МАХ и админ-панель.

**Стек:** React 18 + TypeScript + Vite + Tailwind CSS v4. База данных — localStorage
(таблицы `users`, `services`, `orders`, `events`, `posts`, `content`), при переносе
на сервер переносится 1-в-1 в PostgreSQL/MySQL.

## Быстрый старт

```bash
npm install     # установить зависимости
npm run dev     # локальная разработка (http://localhost:5173)
npm run build   # production-сборка в папку dist
```

## Админ-панель

Откройте **`#/admin`** (ссылка «Для администратора» в подвале сайта).
Первый вход: **admin / valeria** — сразу смените пароль во вкладке «Настройки и документация».

| Вкладка | Возможности |
| --- | --- |
| Заказы | заявки с сайта (+ мини-анкета), смена статусов выпадающим меню: **Новый → Оплачен → Проведена встреча → Закрыт**, фильтры, удаление |
| Витрина | правка всех 9 карточек: название, раздел (индивидуальные/групповые), цена, абонемент, бейдж, кнопки, описание, **загрузка фото** |
| Афиша | добавление/правка/удаление мероприятий (дата, время, онлайн/очно, стоимость) |
| Контент | фото и тексты «Обо мне», блок «Культурный код», **контакты** (телефон, Telegram, ВКонтакте, МАХ), URL автоподгрузки канала |
| Канал | публикации блока «Актуальное из канала» (с фото и датами) |
| Настройки | смена пароля, экспорт/импорт базы (JSON), сброс, документация |

**Резервное копирование:** «Настройки» → Экспорт базы → сохранить JSON.
Восстановление — Импорт базы (например, на новом устройстве).

## Перенос на хостинг / VDS

1. `npm run build` → скопировать содержимое `dist/` в корень сайта.
2. **Статический хостинг** (Netlify/Vercel/GitHub Pages/обычная панель) — просто загрузить `dist`.
3. **VDS + nginx:**
   ```nginx
   server {
     listen 80;
     server_name vash-domen.ru;
     root /var/www/probalance;
     index index.html;
     location / { try_files $uri /index.html; }
   }
   ```
4. HTTPS: `sudo certbot --nginx -d vash-domen.ru`.
5. Перенос данных: экспорт базы на старом устройстве → импорт в админке на новом.

## Интеграция с каналом МАХ

Блок «Актуальное из канала» пробует автоматически подгрузить публикации по URL из
«Контент → URL автоподгрузки» (RSS/JSON, таймаут 4 с, формат: `[{"date","title","text","image"}]`).
Пока публичного API у МАХ нет — поле пустое, блок показывает публикации из вкладки «Канал»
(ручное обновление) и кнопку «Перейти в канал». Как только API появится — достаточно вставить URL.

## Развитие (серверная БД, заявки на почту)

- Таблицы переносятся 1-в-1 в PostgreSQL/MySQL; пароли — bcrypt на сервере.
- Точки замены: `src/lib/db.ts` (loadDB/mutate → fetch на API), `createOrder` →
  POST на сервер + письмо администратору (nodemailer/Telegram-бот).
- Ролевая модель заложена в таблице `users` (поле `role`); сейчас активна роль `admin`.
